# Formation Hub

Créer une plateforme web complète de gestion de centre de formation avec 3 rôles : Administrateur, Formateur et Étudiant.

Référence Design

S'inspirer fortement de l'identité visuelle et de l'expérience utilisateur du site :

MediaFormation.tn

Respecter les éléments suivants :

Design professionnel et moderne

Couleurs proches de la charte graphique du site

Interface élégante et épurée

Grandes sections avec cartes modernes

Typographie professionnelle

Icônes modernes

Animations légères

Responsive Mobile / Tablette / Desktop

Dashboard de style SaaS premium

Expérience utilisateur fluide et intuitive

Attention :
S'inspirer uniquement du style graphique, de l'ergonomie et de l'expérience utilisateur. Ne pas copier directement le contenu, les images ou les éléments protégés par le droit d'auteur.
